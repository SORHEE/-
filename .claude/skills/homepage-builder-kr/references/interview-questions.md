# Phase 1: 요구사항 인터뷰 질문 템플릿

## 진행 규칙 (엄수)

- **반드시 한 번에 한 라운드만 질문한다.** 한 라운드 = 아래 Round 1 ~ Round 6 블록 중 하나.
- 사용자가 해당 라운드의 모든 질문에 답한 것을 확인한 후에만 다음 라운드로 넘어간다.
- **여러 라운드를 한 메시지에 묶어서 보내지 않는다.**
- 답변이 모호하면 같은 라운드 안에서 명확화 질문을 하고, 다음 라운드로 넘어가지 않는다.
- 답변이 충분하지 않으면 반드시 되묻는다. "알아서 해줘" 같은 답도 **그 라운드 안에서** 확정지어야 한다.
- 각 질문의 모호한 답변에는 예시 2~3개를 제시해 선택하게 한다.
- 라운드 순서는 고정: Round 1 → 2 → 3 → 4 → 5 → 6.

## Round 1. 프로젝트 정체성

1. 어떤 종류의 사이트인가요?
   - 예시: (a) SaaS 제품 랜딩페이지, (b) 개인/팀 포트폴리오, (c) 로컬 비즈니스(카페/병원/학원), (d) 커뮤니티, (e) 이벤트/컨퍼런스, (f) 기타
2. 한 문장으로 이 사이트의 목적은 무엇인가요? (예: "프리랜서 디자이너가 잠재 클라이언트에게 작업물을 보여주고 연락받기 위한 사이트")
3. 사이트 이름(가칭)과 로고/브랜드 자산이 있나요?

## Round 2. 타겟과 가치

4. 주요 방문자는 누구인가요? 가능한 한 구체적으로 (나이/직업/상황)
5. 방문자가 겪고 있는 가장 큰 문제(페인 포인트)는 무엇인가요?
6. 이 사이트/제품이 제공하는 핵심 가치 한 가지는?
7. 방문자가 사이트를 떠나기 전에 반드시 해주길 바라는 행동 하나는? (예: 회원가입, 상담 신청, 예약, 구매, 이메일 수집)

## Round 3. 기능 요구사항

8. 다음 중 필요한 기능에 모두 체크해주세요:
   - [ ] 회원가입/로그인 (이메일/소셜)
   - [ ] 결제 (구독/단건)
   - [ ] 블로그/콘텐츠 관리
   - [ ] 문의 폼 (이메일 전송)
   - [ ] 예약 시스템
   - [ ] 다국어 (한/영 등)
   - [ ] 관리자 페이지
   - [ ] 사용자 대시보드
   - [ ] 파일 업로드
   - [ ] 검색
   - [ ] 댓글/리뷰
   - [ ] 알림 (이메일/푸시)
9. 데이터베이스에 저장해야 하는 정보가 있나요? (예: 사용자 정보, 상품, 예약 내역, 게시글)

## Round 4. 디자인 방향

10. 좋아하는 웹사이트 레퍼런스 URL이 있다면 2~3개 알려주세요. 또는 다음 키워드 중 선택:
    - **미니멀**(여백 많음, 절제된 색), **대담/힙**(큰 타이포, 강한 컬러), **럭셔리**(세리프 + 골드/블랙), **플레이풀**(파스텔, 부드러운 도형), **브루탈리즘**(날것의 레이아웃), **글래스모피즘**(블러/반투명), **벤토 그리드**(카드 조합), **다크 테크**(네온 + 블랙)
11. 다크모드 지원이 필요한가요? (라이트 전용 / 다크 전용 / 둘 다)
12. 강조색(primary color) 선호가 있나요? 없으면 AI가 업종에 맞게 추천

## Round 5. 콘텐츠와 운영

13. 지금 당장 넣을 수 있는 실제 콘텐츠가 얼마나 있나요? (로고, 사진, 소개글, 제품 정보 등)
14. 없는 콘텐츠는 플레이스홀더로 채워도 되나요, 아니면 AI가 그럴듯한 한국어 예시를 생성해도 되나요?
15. 언어: 한국어 전용 / 한국어+영어 병기 / 다국어(i18n 구조 필요)

## Round 6. 배포 환경

16. 도메인을 이미 가지고 있나요? (없으면 먼저 Vercel 기본 도메인으로 배포 후 나중에 연결)
17. Supabase 계정이 있나요? 없으면 만드는 방법부터 안내
18. Vercel 계정이 있나요? (GitHub 계정이 있으면 5초 만에 연동 가능)
19. GitHub 레포지토리를 만들어서 연동할까요, 아니면 Vercel CLI로 직접 배포할까요?

## 라운드 종결 체크리스트

각 라운드 끝에서 다음을 확인한 후에만 다음 라운드로 넘어간다:

- [ ] 라운드 내 모든 질문에 답변이 있는가?
- [ ] "알아서 해줘" 같은 답변이 있다면 **그 라운드 안에서** 확정되었는가?
- [ ] 답변끼리 모순이 없는가? (있다면 같은 라운드에서 재확인)
- [ ] 예시가 필요했던 질문에 실제로 선택이 이뤄졌는가?

체크가 모두 통과되면 간단히 요약 (1~3줄)한 뒤 다음 라운드로 진행한다.
모든 라운드(1~6)가 끝나면 Phase 2의 "아키텍처 결정 요약"을 생성해 최종 확인한다.

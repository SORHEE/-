# 한국어 카피 프레임워크

PAS/AIDA/BAB를 **한국어 어법**에 맞게 번안. 영어 직역체 금지.

---

## 공통 원칙

1. **헤드라인은 짧게** — H1은 15자 이내 권장, 20자 이내 강제
2. **구체 > 추상** — "비즈니스를 혁신하세요" X / "하루 2시간, 리포트 대신 고객 만나기" O
3. **존댓말 vs 반말** — 브랜드 톤에 따라 결정하되 **한 사이트 안에서 섞지 않는다**
4. **CTA는 동사형** — "무료로 시작하기", "3분 만에 가입하기", "지금 상담 받기"
5. **숫자 적극 활용** — "87% 빠른", "3초 만에", "월 9,900원부터"
6. **금지 표현**: "당신의 [X]를 변화시키세요", "차세대 [X] 솔루션", "혁신적인", "최첨단", "이제는 [X]의 시대"

---

## PAS (Problem → Agitate → Solution)

문제를 꺼내서 자극한 뒤 해결책 제시. **B2B SaaS / 생산성 도구**에 강함.

**구조**
- H1: 지금 겪고 있는 고통 (직설적)
- Sub: 그 고통이 계속되면 벌어지는 일
- CTA: 우리 솔루션

**한국어 예시 — 리포트 자동화 SaaS**
- H1: "매주 금요일, 또 리포트 만드세요?"
- Sub: "3시간짜리 엑셀 정리가 없어지면 그 시간에 고객 미팅 하나를 더 할 수 있습니다."
- CTA: "10분 만에 자동화 시작하기"

---

## AIDA (Attention → Interest → Desire → Action)

주목 → 관심 → 욕구 → 행동. **소비재/이커머스/이벤트**에 강함.

**구조**
- H1: 시선 잡는 과감한 선언
- Sub: 흥미로운 사실/혜택 한 줄
- Features: 욕구 키우는 증거
- CTA: 명확한 행동

**한국어 예시 — 프리미엄 원두 구독**
- H1: "매달, 세계 1%의 원두가 집으로."
- Sub: "Q등급 이상만 선별해 로스팅 7일 이내 발송합니다."
- CTA: "첫 달 50% 할인 받기"

---

## BAB (Before → After → Bridge)

현재(Before) → 미래(After) → 다리(Bridge). **변화/전환**을 파는 제품.

**구조**
- H1: "[현재 상태] → [바뀐 상태]"
- Sub: "[제품]이 그 간극을 메웁니다"
- Features: 어떻게 메우는가

**한국어 예시 — 영어 코칭 서비스**
- H1: "매일 단어장만 보던 3년 → 3개월 후 화상 미팅 리드"
- Sub: "원어민 튜터와 주 2회 30분, 그게 전부입니다."
- CTA: "레벨 테스트 받기"

## 섹션별 카피 가이드

### Hero
- H1 + Sub 1문장 + CTA 1개(또는 2개)
- 신뢰 요소 1줄 ("이미 2,300개 팀이 사용 중")

### Features (3~6개)
- 각 기능 제목: **결과 중심 7자 이내**
  - 좋음: "3초 만에 보고서", "월말 마감 자동"
  - 나쁨: "AI 기반 리포팅 엔진"
- 설명: 1~2문장, 구체적 수치/시나리오

### Pricing
- 티어 이름: Starter/Pro/Enterprise 보다 **한국어 + 명확**
  - "무료", "성장", "팀" 같은 단계형
  - "개인", "스튜디오", "에이전시" 같은 대상형
- 가격 밑에 핵심 혜택 한 줄 ("매달 100건까지 무료")
- "부가세 별도" 또는 "부가세 포함" 반드시 명시

### Testimonials
- 실명 + 소속 + 얼굴 사진
- 후기는 **구체적 숫자** 포함 ("도입 후 응대 시간이 40% 줄었어요")

### FAQ
- 진짜 자주 묻는 질문만 (5~8개)
- 환불, 해지, 데이터 보안, 지원, 가격 변경
- 답변은 **짧고 정직하게**

### CTA (마지막 섹션)
- "지금 시작하세요. 신용카드 필요 없습니다."
- "무료 상담 받기" (B2B)
- "30일 무료 체험" (SaaS)

### Footer (법적 필수 — 한국)
사업자가 있는 경우 반드시:
- 상호명 / 대표자명 / 사업자등록번호
- 주소 / 전화 / 이메일
- 통신판매업 신고번호 (해당 시)
- 개인정보처리방침 링크
- 이용약관 링크

# 섹션 템플릿 프리셋

프로젝트 유형별 추천 섹션 구성. Phase 1 인터뷰 답변을 바탕으로 **추천안을 제시**하고 사용자가 추가/제거하도록 확인한다.

---

## 유형별 기본 섹션 구성

### SaaS 랜딩
```
Hero → 신뢰 로고 바 → Features (문제-해결 구조) → How it works (3단계)
→ Testimonials → Pricing → FAQ → CTA → Footer
```

### 포트폴리오
```
Hero (이름+한 줄 소개+CTA) → About → Selected Works (3~6개 프로젝트 그리드)
→ Skills/Tools → Experience/Timeline → Contact → Footer
```

### 로컬 비즈니스 (카페/병원/학원)
```
Hero (대표 이미지+위치+영업시간) → 주요 서비스/메뉴 → 공간/분위기 갤러리
→ 고객 후기 → 찾아오시는 길 (카카오맵 임베드) → 예약/문의 CTA → Footer
```

### 커뮤니티
```
Hero (슬로건+가입 CTA) → 커뮤니티 소개 → 활동/이벤트 → 멤버 소개
→ 최근 글/활동 → 가입 CTA → Footer
```

### 이벤트/컨퍼런스
```
Hero (제목+날짜+장소+티켓 CTA) → 소개 → 스피커 → 아젠다
→ 주최/후원 → 장소 안내 → 티켓 구매 CTA → Footer
```

## Hero 섹션 5가지 변형 (landing-page-generator 기반)

1. **Centered** — 가운데 정렬, 헤드라인 + 서브 + CTA 2개. 가장 안전한 기본값.
2. **Split** — 좌측 텍스트 + 우측 이미지/스크린샷. 제품이 시각적일 때.
3. **Gradient** — 풀블리드 그라데이션 배경. 브랜드 색 강조.
4. **Video Background** — 배경 루프 비디오. 라이프스타일/레스토랑/럭셔리.
5. **Minimal** — 거대한 타이포그래피 + 최소 요소. 포트폴리오/에이전시.

### Hero 필수 구성
- **H1**: 15자 이내 권장, 가치 제안을 구체적으로
- **Sub**: 1~2문장, H1을 보강하는 설명
- **Primary CTA**: 가장 원하는 행동 ("무료로 시작하기")
- **Secondary CTA** (선택): 낮은 허들 ("작동 원리 보기")
- **신뢰 요소** (선택): 사용자 수, 로고 바, 별점

## Features 섹션 패턴

- **3/4-Column Grid** — 균형 잡힌 기능 나열 (각 아이콘+제목+1문장)
- **Alternating (Zig-Zag)** — 스크린샷+텍스트 교차 배치, 기능 2~4개를 깊게 설명
- **Bento Grid** — 크기가 다른 카드 조합, 시각적 임팩트 최대
- **Icon Tiles** — 8~12개 기능을 작은 아이콘 카드로 나열

**규칙**: 기능 제목은 **동사형** 또는 **결과 중심** ("3초 만에 보고서 생성" O / "AI 기반 리포트" X)

## Pricing 섹션

- 2~4 티어가 표준. 3티어가 가장 전환율 높음.
- **중간 티어 강조** (테두리/배경색 + "인기" 라벨)
- 월/연 토글 (연 결제 할인 강조)
- 기능 리스트는 **상위 티어가 하위 티어 포함**하는 누적 구조
- 최상단에 "부가세 별도/포함" 명시 (한국 B2B 필수)

---

## FAQ 섹션

- 아코디언 형태, 기본 모두 접힘
- 질문 5~8개가 적정
- **진짜 자주 묻는 질문**만 넣기 (환불, 해지, 데이터 보안, 지원 언어 등)
- Schema.org FAQPage JSON-LD 구조화 데이터 필수

---

## Testimonials 섹션

- **Grid (3개)** — 가장 안전
- **Carousel** — 공간 절약, 인터랙션 있음
- **Single Quote** — 단 하나의 킬러 후기 강조
- 각 후기에 **이름, 직함/회사, 얼굴 사진** 필수 (없으면 이니셜 아바타)
- 가짜 후기 생성 절대 금지 — 없으면 섹션 자체를 빼거나 "준비 중"으로

---

## CTA 섹션 (마지막)

- 풀블리드 배경 + 거대한 헤드라인 + 단일 CTA
- 헤드라인은 **Hero와 다르게** 마지막 설득용 문구로
- 예: "지금 시작하세요. 신용카드 없이 3분이면 됩니다."

---

## Footer

- **Mega Footer**: 사이트맵 + 뉴스레터 + 소셜 + 법적 링크 (B2B/SaaS)
- **Simple Footer**: 저작권 + 이메일 + 소셜 아이콘 (포트폴리오/소규모)
- **필수 포함 (한국)**: 사업자등록번호, 대표자명, 주소, 연락처, 개인정보처리방침, 이용약관 (해당 시)

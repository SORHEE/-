# 네이버 블로그 글쓰기 구조

지니뷰티랩 마케팅 강의(2026-08-21 클로바노트 전사본) 기반. 네이버 블로그 포스팅 한 편을 쓸 때 아래 순서대로 전부 적용한다 — 어느 하나만 빠져도 전환율이 떨어진다.

## 0. 전제조건 — 키워드 검색의도부터 확정

**구조를 아무리 잘 짜도 키워드 검색의도가 안 맞으면 소용없다.** 글을 쓰기 전에 반드시:

1. **키워드 종류 판별**
   - **정보탐색 키워드**: 아직 구매/방문 의사 없이 정보만 궁금한 단계 (예: "어금니 통증 원인", "초등 영어 단어")
   - **구매직전 키워드**: 지갑 열 준비된 단계, 지역명+업종/추천/잘하는곳 형태 (예: "압구정 치과 추천", "과천 영어학원")
   - 이 둘은 완전히 다른 글이어야 한다. 정보탐색 키워드에 홍보성 글을 쓰거나 구매직전 키워드에 원인·정보 글을 쓰면 안 된다.
2. **본능 분석 반박 제거**: 이 키워드를 검색한 사람이 어떤 상황·어떤 궁금증으로 검색했는지 먼저 규정한다. 확인 안 되면 네이버 카페·지식인·당근마켓·유튜브 댓글·플레이스 후기에서 실제 검색어(예: "치과 추천")로 검색해 사람들이 실제로 뭘 물어보는지(과잉진료 여부, 친절한지, 안 아픈지 등) 읽고 그 궁금증을 글 안에서 해소하도록 설계한다.
3. **키워드 검색량 확인**: 마피아넷 또는 네이버 키워드도구에서 월간 검색량 확인. **20건 이상**을 유효 키워드로 보되, 처음에는 **200건 이내**(경쟁 덜한 롱테일)를 우선 잡는다. 0건 키워드는 잡지 않는다.
4. 같은 키워드로 반복 발행하지 않는다 (1블로그당 1키워드 노출이 기본이라 의미 없고, 과도한 동일키워드 반복 발행은 상업성으로 감점될 수 있음).

## 1. 본문 구조 — PREP(주장→근거→예시→재주장)

섹션마다 이 4단계를 반복해서 쌓는다:

1. **주장(Point)** — 짧고 단정적인 한 문장 주장
2. **근거(Reason)** — 왜 그런지 이유
3. **구체적 예시/상황(Example)** — 비교 대상(안 좋은 예시) 또는 구체적 사례로 근거를 체감시킴
4. **재주장(Point 재확인)** — 처음 주장을 다시 한 번 짧게 정리

이 4단계 블록을 섹션마다(보통 3~5개 섹션) 반복해서 본문을 쌓는다. 예:
> 주장: "1회 관리만으로 비포·애프터가 뚜렷합니다" → 근거: "일시적 스케일링이 아니라 근본 원인을 다루는 맞춤 케어라서" → 예시: "일반 관리는 강한 알칼리·계면활성제로 자극하지만, 우리는 약산성+살리실릭애시드로 자극 없이 각질을 제거" → 재주장: "그래서 1회만으로도 육안으로 확인되는 변화가 나온다"

## 2. 이미지 전략 — 업종별 "반박 제거" 자료

이미지도 본능분석반박제거로 고른다: "이 키워드를 검색한 사람이 뭘 의심할까"를 먼저 뽑고, 그 의심을 깨는 이미지를 배치한다.

**공통으로 항상 쓸 수 있는 것**: 얼굴+강점을 보여주는 가치입증표(도입부), 실제 고객 후기, Before/After, 고객사 로고(B2B), 강의·수상 이력, 문의량 캡처(카톡/DM/홈페이지 문의창)

**업종별 예시**:
| 업종 | 추천 이미지 |
|---|---|
| 학원 | 강의/연구 모습, 성적 인증·향상 사례, 소통 사진, 분석 자료(시험지), 쾌적한 교육환경 |
| 부동산 | 자격증/수료증, 매물 내부, 고객과의 친절한 소통 메시지, 상담 모습 |
| PT·필라테스 | Before/After, 후기 캡처, 시설·기구 청결 관리 모습, 티칭 모습, 수료증 |
| 에스테틱 | Before/After, 사용 제품(저가 아님을 증명), 원장·관리사 단체사진, 내부 교육 모습 |
| 인테리어 | Before/After, 대표 얼굴, 클라이언트 소통 후기, 시공 현장, 등록증 |
| 제조업 | 고객사 로고, 클라이언트 후기, 공장/작업 과정, 완성물 |
| 요식업 | 조리 과정, 먹음직스러운 완성 이미지 |

## 3. 글 하단 CTA — 3가지 공식

CTA는 반드시 **납득 가능한 이유와 함께** 붙인다("~하지 마세요"가 아니라 "~때문에 ~해주세요").

1. **능력 한계치 인정**: 우리 한계 또는 최대효과 조건을 인정하며 고객을 한정. 예) "일주일 최소 2시간 투자 못하시면 저희 플랜으로는 효과 보기 어렵습니다, 가능하신 분만 신청해주세요"
2. **희소성**: "다 준다"가 아니라 "제한한다"는 걸 이유와 함께. 예) "한 분 한 분 꼼꼼히 보기 위해 하루 2건만 진행합니다"
3. **인기성**: 이미 많이 찾는다는 근거. 예) "5월 예약 마감 임박", "타지역(강남·인천)에서도 찾아옵니다", "하루 10건 넘는 문의로 통화 연결이 늦을 수 있습니다"

**CTA 뒤에는 반드시 실제 연락 창구(전화번호/네이버 톡톡/플레이스 링크)를 붙인다.** 이미지에 전화번호 링크를 걸어 클릭 시 바로 통화 연결되게 하는 것도 활용.
**금지**: "지금 바로 전화주세요", "언제든 통화 가능" 같은 막연한 촉구는 지양 — 항상 위 3공식 중 하나로 가치를 실어서 표현.

## 4. 하단부 랜딩 전략

CTA 옆/아래에 **다음에 읽힐 글 링크**를 배치해서 내 블로그 안에서 전환까지 이끈다.
- 정보탐색 글 → 업체소개 글로 랜딩
- 업체소개/성공사례 글 → 스토리텔링 글(대표 서사)로 랜딩
- 진행 중인 이벤트/개강 글도 같이 첨부 가능
목적: "이 글 하나로 끝"이 아니라 궁금해진 사람을 다음 글로 넘겨서 최종 전환까지 붙잡는 것.

## 5. 상위노출 8원칙 (1~7위 노출 기준)

1. **키워드는 제목 맨 앞**에 배치 (뒤보다 눈에 잘 띄고 유리)
2. **글자수 공백제외 1400~1800자** (너무 적으면 정보부족, 너무 많으면 이탈률↑)
3. **키워드를 제목+본문 합쳐 5~6회 반복** (본문/소제목/이미지캡션에 자연스럽게)
4. **이미지 개수는 상위 노출 경쟁글 평균에 맞춘다** (해당 키워드 검색 후 1~5위 글의 이미지 수 확인)
5. **이미지 재사용 지양** — 같은 사진 반복 시 유사문서로 잡혀 노출 누락 위험. 재사용해야 하면 편집(필터/보정/좌우반전/자르기)하거나 메타데이터 삭제(우클릭→속성→자세히→속성 및 개인정보 제거→복사본 만들기)
6. **외부링크(유튜브/인스타/카톡/타 홈페이지) 자제** — 특히 신규 블로그는 보수적으로. 넣더라도 글 하나에 1개 이내, 구매직전 키워드 글에만. 네이버 자체 서비스(플레이스/톡톡/스마트스토어) 링크는 무제한 사용 가능
7. **제목-도입부 연결성** — 제목의 단어/문장을 도입부에 그대로 또는 변형해서 반복 (낚시성 제목 방지 신호)
8. **특정 단어 반복은 20회 미만** (이상적으론 15회 이내) — 넘으면 동의어로 교체하거나("필라테스"↔"센터"), 온점+크기축소 또는 띄어쓰기 삽입으로 우회. 컨트롤+F로 개수 확인

## 6. 가독성 10원칙

1. 강조·소제목·공감문구에 **인용구 효과** 사용
2. **폰트**: 손글씨체(다시 시작해·바른히피·우리딸손글씨체 등) 제외, 편안한 서체
3. **폰트 크기 16pt** 기본, 주 독자층이 50~60대면 19pt
4. 핵심 단어/문장은 **볼드체·밑줄**
5. **이미지 캡션**에 짧은 설명 입력 (그냥 붙이지 말 것)
6. **글자색·하이라이트**는 정말 강조할 곳에만 (과하면 역효과)
7. **줄간격(행간) 180~200%**
8. **문단 길이 2~3문장**, 문단 사이 공백 2칸
9. **정렬은 왼쪽 또는 양끝 정렬** (가운데 정렬 지양 — 부득이하면 모바일에서 호흡 안 끊기게 문장 조절)
10. 이미지·GIF 적절히 배치, **모바일 미리보기로 최종 확인 후 발행** (PC보다 모바일 검색 비중이 높음)

## 7. 키워드 확장 전략 (꾸준히 운영할 때)

블로그 통계(관리→통계) 활용, 3가지:
1. **오래됐지만 조회수 잘 나오는 글** — 조회수 순위 탭에서 6개월 이상 된 인기글을 동일 주제로 최신 재발행 (네이버는 최신성 우대)
2. **유입 키워드** — 유입분석→검색유입에서 내가 안 잡았던 키워드 발견 → 검색량 20건 이상이면 그 키워드로 신규 발행. 플레이스 유입 키워드도 동일하게 확인
3. **홈판 노출글 분석** — 유입분석에서 "네이버 메인 모바일 홈판" 노출 이력 있는 글들을 모아 AI(클로드 등)에게 "이 글들의 공통점을 분석해줘"로 패턴을 뽑고 다음 글에 반영

## 체크리스트 (발행 전 최종 확인)

- [ ] 이 키워드, 정보탐색인지 구매직전인지 명확히 구분해서 글을 썼는가
- [ ] PREP(주장→근거→예시→재주장)로 섹션이 쌓여있는가
- [ ] 업종에 맞는 반박제거 이미지가 들어갔는가
- [ ] CTA 3공식 중 하나 + 연락창구가 하단에 있는가
- [ ] 다음 글로 랜딩되는 링크가 있는가
- [ ] 글자수 1400~1800자, 키워드 5~6회, 특정단어 20회 미만인가
- [ ] 가독성 10원칙(폰트/볼드/줄간격/문단/정렬) 적용했는가
- [ ] 모바일 미리보기로 확인했는가

# 네이버 블로그 → 인스타 카드뉴스 → 스레드 자동 발행 대시보드

매일 (1) 네이버 블로그 글을 자동 생성·발행하고, 그 글을 원본 삼아 (2) 인스타그램 카드뉴스와
(3) 스레드(Threads) 글타래 초안을 자동으로 만들어주는 로컬 프로그램입니다. 대시보드(로컬
웹페이지)에서 글감 확인 → 초안 확인 → 발행까지 누르면 되고, `node-cron`으로 매일 정해진
시각에 자동 실행되도록 예약도 됩니다.

> **중요**: 이 프로그램은 본인 컴퓨터(Windows)에서 직접 실행해야 합니다. 네이버 로그인은
> 실제로 화면에 뜨는 브라우저 창에서 본인이 직접 로그인해야 하고, `node-cron` 자동 발행은
> 이 프로그램이 켜져 있는 동안(컴퓨터가 켜져 있고 `npm start`가 실행 중인 동안)만 동작합니다.

## 인스타그램·스레드는 "반자동"입니다

인스타그램/스레드는 카드뉴스 이미지·캡션·글타래까지 전부 자동으로 만들어서 대시보드에
준비해두지만, **실제 업로드 버튼은 사용자가 인스타/스레드 앱·웹에서 직접 눌러야 합니다.**
Meta(인스타그램·스레드)는 공식 API 이외의 자동 업로드를 약관으로 금지하고 있어(계정 정지
위험), 완전 자동 업로드는 구현하지 않았습니다. 네이버는 공식 오픈 API가 없어 스마트에디터
자동 입력 방식(Playwright)으로 발행까지 자동화되어 있습니다 — 본인 계정 1개, 하루 1건
발행이라는 개인적 사용 범위를 벗어나지 않게 사용해주세요.

## 1. 사전 준비 (Windows) — 더블클릭만으로 하는 방법

명령어를 직접 입력하지 않아도 되도록 더블클릭용 파일을 만들어뒀습니다.

1. [Node.js 20 이상](https://nodejs.org/)을 먼저 설치하세요 (설치 파일 실행 → 계속 다음 →
   완료. 설치 후 컴퓨터를 껐다 켤 필요는 없지만, 열려 있던 PowerShell/명령 프롬프트 창은
   새로 열어야 인식됩니다).
2. 이 저장소를 zip으로 내려받아 원하는 폴더(예: 바탕화면)에 압축 해제하세요.
3. 압축을 푼 폴더를 열어보면 `1_설치하기.bat`, `2_시작하기.bat` 파일이 보입니다.
   - **`1_설치하기.bat`를 더블클릭**하세요. 검은 창이 뜨고 설치가 진행됩니다(몇 분 걸릴 수
     있음). "Windows에서 PC를 보호했습니다"라는 파란 경고가 뜨면 **"추가 정보"** 클릭 →
     **"실행"** 클릭하면 됩니다(직접 받은 정상 파일이라 안전합니다). 끝나면 아무 키나 눌러
     창을 닫으세요.
   - 그다음 **`2_시작하기.bat`를 더블클릭**하세요. "대시보드: http://localhost:3000"이라는
     줄이 보이면 성공입니다 — 이 창은 닫지 말고 그대로 두세요.
4. 이제 브라우저(크롬/엣지)를 열고 주소창에 `http://localhost:3000`을 입력하면 대시보드가
   나옵니다.

## 2. Claude 로그인 (구독 인증 — API 과금 없이 사용)

이 프로그램은 **ANTHROPIC_API_KEY(종량제 API 과금)를 절대 사용하지 않습니다.** 아래 둘 중
하나만 하면 됩니다.

- **방법 A (가장 간단)**: 이 컴퓨터에 [Claude Code](https://code.claude.com) CLI를 설치하고
  `claude` 실행 후 `/login`으로 로그인해두면, 이 프로그램이 그 로그인 세션을 그대로 사용합니다.
- **방법 B (터미널 로그인이 번거로울 때)**: 터미널에서 아래 명령을 실행해 토큰을 발급받고
  ```powershell
  claude setup-token
  ```
  출력된 값을 `.env` 파일(`.env.example`을 복사해서 `.env`로 만드세요)의
  `CLAUDE_CODE_OAUTH_TOKEN=` 뒤에 붙여넣으세요.

만약 환경변수에 `ANTHROPIC_API_KEY`가 실수로 설정되어 있으면, 프로그램 실행 시 자동으로
감지해서 지우고 구독 인증으로 진행합니다(콘솔에 경고가 뜹니다).

이 프로그램은 **본인 개인 자동화 용도**로만 사용하세요. 다른 사람에게 이 프로그램을 나눠주면서
그 사람들의 로그인을 대신 처리하는 서비스로 확장하는 것은 Anthropic 이용약관상 허용되지
않습니다.

## 3. 설정값 채우기

`config/settings.json`을 열어 아래 값을 채워주세요:

| 필드 | 설명 |
|---|---|
| `naverBlogId` | 네이버 블로그 아이디 (blog.naver.com/**이 부분**) |
| `naverBlogCategoryNo` | 발행할 카테고리 번호 (비워두면 기본 카테고리) |
| `keywords` | 관심 키워드 배열, 예: `["여드름 관리", "지성 피부"]` |
| `targetAudience` | 타깃 독자 설명 |
| `tone` | 글의 말투 |
| `cta` | 마무리에 유도할 CTA (`label`, `value` — 링크나 오픈채팅 등) |
| `publishTime` | 매일 자동 발행 시각, `"HH:MM"` 형식 |
| `openType` | `"public"`(전체공개) 또는 `"private"`(비공개, 테스트용) |
| `instagramHandle` / `threadsHandle` | 참고용 계정명 (자동 업로드에는 쓰이지 않음) |

## 4. 실행

`2_시작하기.bat`를 더블클릭하세요(이미 실행 중이면 그대로 두면 됩니다). 콘솔에 뜨는 주소
(기본 `http://localhost:3000`)를 브라우저로 열면 대시보드가 나옵니다.

1. **네이버 로그인** 버튼 클릭 → 새로 뜨는 브라우저 창에서 직접 로그인 → 자동으로 세션 저장
   (`.auth/naver.json`). 이후에는 세션이 만료되기 전까지 다시 로그인할 필요 없습니다.
2. **글감 후보 보기** 또는 직접 주제 입력 → 초안 생성
3. 초안 확인 (내용이 마음에 안 들면 새로고침해서 다시 만들 수 있습니다)
4. **네이버에 발행** 클릭 → 발행 완료되면 인스타 카드뉴스 이미지·캡션, 스레드 글타래가 자동으로
   준비됩니다 → 캡션 복사 후 인스타/스레드 앱에서 직접 업로드

`npm start`를 실행해둔 채로 컴퓨터를 켜두면, `config/settings.json`의 `publishTime`에 맞춰
매일 자동으로 위 1~4번(로그인은 미리 되어 있어야 함) 과정이 실행됩니다. 네이버 로그인이
안 되어 있으면 그날은 건너뛰고 대시보드 발행 이력에 실패 사유가 남습니다.

### 발행 전 미리 테스트해보기 (dry-run)

실제 네이버 로그인·발행 없이, 콘텐츠 생성 → 품질 규칙 적용 → 이미지 렌더까지만 해보고
결과물을 `output/<날짜>/` 폴더에서 확인할 수 있습니다:

```powershell
npm run dry-run
```

## 5. 네이버 에디터 자동입력이 안 될 때

네이버 스마트에디터 ONE의 화면 구조는 종종 바뀝니다. 자동입력이 실패하면 `config/selectors.json`
파일 하나만 고치면 됩니다(다른 코드는 건드릴 필요 없음):

1. 네이버 블로그 글쓰기 화면에서 F12(개발자도구) → 안 되는 부분(제목/본문/이미지 버튼/발행
   버튼/공개범위 라디오 등)을 우클릭 → "검사"
2. 실제 class명/id를 확인해서 `config/selectors.json`의 해당 값을 교체

특히 공개범위 라디오(`open_type`, `#open_private`/`#open_public`)는 발행 직전에 실제로
선택됐는지 자동으로 검증하고, 확인이 안 되면 발행을 중단하도록 만들어져 있습니다(의도치 않은
공개범위로 발행되는 사고 방지).

## 폴더 구조

```
config/settings.json   # 사용자가 채우는 설정값
config/selectors.json  # 네이버 에디터 selector 모음 (UI 바뀌면 여기만 수정)
.auth/                 # 로그인 세션 저장 (git에 올라가지 않음)
data/                  # 발행 이력, 이미지/주제 중복 방지 기록
output/<날짜>/         # 그날 생성된 블로그 이미지, 인스타 카드뉴스, 스레드 글타래
src/                   # 서버 및 파이프라인 코드
public/                # 대시보드 정적 파일
.claude/skills/        # naver-blog-writing, marketing-science-writing 등 글쓰기 스킬
```
